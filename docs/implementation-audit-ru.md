Порог приёмки — 9,5 из 10 по каждому критерию. Баллы отражают оценку проверенных сценариев.

В независимом прогоне на Linux с Python 3.12 и Qt offscreen прошли 216 тестов, ещё два предназначены для Windows. В отдельном сценарии после перевода книги А через тестовый провайдер выбор книги Б закрыл временный файл адресов и очистил итог. В книге Б на 8 009 глав через диалог выбраны 4 000 записей по поиску. Границы составили записи 3 и 8 001, длина команды в Windows-сериализации — 303 кодовые единицы UTF-16, временный файл выбора удалён после завершения. Отдельно сверены события CLI для повторяемого аргумента и файла выбора с переставленными и повторяющимися номерами.

## Воспроизводимая проверка

```bash
uv sync --locked --extra desktop
QT_QPA_PLATFORM=offscreen uv run --no-sync python -m unittest discover -s tests -v
QT_QPA_PLATFORM=xcb xvfb-run -a uv run --no-sync python -m unittest discover -s tests -p test_desktop.py -v
```

На Linux с Python 3.11.18 и 3.12.3 в каждом полном offscreen-прогоне из 218 тестов прошли 216 и были пропущены два теста Windows. На Python 3.12 установленный вне репозитория wheel прошёл также 54 теста Desktop под X11. Проверки пользуются фиктивными провайдерами. Нативные прогоны Windows и macOS, живые модельные сервисы, пользовательский замер времени и слепая литературная вычитка остаются за пределами локальной проверки. Промпты и правила литературной проверки сохранены.

## Замеры

Linux, Python 3.12.3, GNU time. Синтетические TXT, FB2 и EPUB содержат по 1 000 глав, в каждой заголовок и 100 коротких абзацев. Для каждой пары «формат и действие» проводятся по три измерения каждой версии на одинаковых файлах. Время включает старт процесса, а пиковый RSS измеряется для CLI. Поиск в уже загруженном Qt-каталоге измеряется отдельно.

```bash
base="$(mktemp -d)"
git archive 2a77218 src | tar -x -C "$base"
QT_QPA_PLATFORM=offscreen uv run --no-sync python scripts/benchmark_catalog.py --compare "$base" --qt-search
```

После перехода к модели списка Qt медиана фильтрации загруженного каталога составила 1,44 мс при 1 000 записях и 10,64 мс при 8 000 записях. Максимумы были 3,62 и 35,54 мс соответственно. Замер сделан на Qt offscreen с обработкой событий. Модель обновляет строки одним сбросом. Это устраняет аварийное завершение, воспроизведённое с PySide6 6.12 на Python 3.11 при тысячах поэлементных вызовов.

Код каталога TXT использует общий декодер и правила границ, подсчитывая блоки без объектов перевода и функций записи для каждой строки.

## Отложенные гипотезы

Импорт документов других форматов, OCR, публикация на площадках, параллельная очередь, отдельный EPUB/FB2 для выбранных глав и новый платный межглавный анализ остаются отдельными задачами.
